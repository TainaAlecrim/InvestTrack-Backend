# Registro de decisões técnicas

Decisões relevantes serão registradas nesta pasta, com contexto, decisão, alternativas consideradas e consequências.

Formato sugerido:
- Identificador: DEC-XXX
- Título
- Status: proposta, aprovada ou substituída
- Contexto
- Decisão
- Consequências

Nenhuma decisão arquitetural deve ser considerada definitiva apenas por aparecer na direção técnica inicial do README.
